My Web Technologies

Here are the top five Web Technologies that I use:

  1. Teams: Microsoft Teams is my default platform for communicating efficiently with lecturers and students at EIT.
  2. VSCode: When writing code, I have always used VSCode since I discovered it in secondary school. The interface, colour-coding and auto-completion options make code writing a lot more efficient than if it was written in a standard text document.
  3. Github: I have used Github frequently during certain courses in the past. It allows me to record/update documentation, upload files and host websites.
  4. Word: Microsoft Word allows me to edit documents in ways that simplified options like Google Docs doesn't offer, such as saving the documents as actual files that can be easily sent.
  5. Notion: I used Notion for a group assessment during one of my courses and I found it very easy and convenient to use. It allows for notes and details to be conveniently written and formally structured.
